核心闭环

  1. 选择身份进入诊断，回答事务、索引等原创题目
  2. 提交答案服务端判分，形成知识点掌握情况
  3. 写入记忆薄弱点与掌握变化写入 PowerContext，返回记忆标识
  4. 新会话读取以相同身份读回记忆，优先安排薄弱点并说明依据
  5. 再次答题更新记忆，导出可核验的学习过程记录

真实记忆，不是本地缓存

学习记忆存放在 PowerContext 原子记忆中，通过公开 Python Client SDK 读写；页面上每条依据都能对应到 atomic-memory/art_…@修订号。

固定内置题库

题库为原创内置内容，答题与判分不调用任何模型服务，因此核心闭环无需模型 API 密钥。

隔离与可撤回

每个学习身份独占一个 PowerContext Scope；支持按条遗忘与一键清空，遗忘条目退出召回但历史仍可核验。

这是数据层面的隔离：本作品没有登录与授权，身份标识不是凭证， 只适合本机或受信任内网使用（详见 RUNBOOK 第 8 步）。
