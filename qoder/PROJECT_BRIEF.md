# 拾忆 · Recall Coach

面向需要持续复习数据库基础知识的学生，解决“换一次会话就要重新交代薄弱点、复习计划与答题表现脱节”的问题。

## 比赛约束

- 基于 OceanBase PowerContext 的 `2026-competition-ecosystem` 分支；全部作品资产放在 `qoder/`。
- 主要功能须由真实 Qoder 会话开发；保留原始会话、关键截图或录屏与账号 UID，不补造记录。
- 实际使用 PowerContext 保存并读取学习记忆，读取结果必须影响后续复习安排。
- 项目展示网站通过 Qoder Sites 发布，允许未登录访客访问；网站可提供独立运行项目的体验入口与复现说明。
- 源码、安装启动说明、验证样例、技术作用证据、开发记录均须可核验。
- 不提交密钥；不捏造用户、访问次数、提效结果或反馈。

## 核心流程

1. 选择学习身份，进入数据库基础诊断，回答事务、索引等原创示例题。
2. 提交答题结果：由服务端判分，形成知识点掌握情况。
3. 将薄弱点、掌握变化、复习偏好等写入真实 PowerContext；展示可追踪的记忆标识与操作结果。
4. 开启新会话或重启应用后，以相同身份读取已有记忆，优先安排薄弱知识点并说明依据。
5. 再次答题，更新记忆并查看可导出的学习过程记录。

## 最小交付边界

- 中文网页：概览、诊断与复习、学习记忆、验证说明；适配手机与桌面。
- 原创内置题库：无需额外模型密钥即可演示完整闭环；明确题目属于固定题库，不声称动态 AI 出题。
- PowerContext 使用公开 SDK 或 HTTP API，固定依赖版本；优先采用可本机部署的持久存储方案。
- 实际服务不可用时明确报错，不以模拟数据冒充真实记忆读写。
- 不同学习身份的数据隔离；公开展示避免泄露用户学习记录。
- 自动化验收覆盖跨会话/重启持久性、记忆驱动选题、不同身份隔离和写入失败。
- 验证材料记录实际运行命令与结果；截图和录屏须来自真实执行。
